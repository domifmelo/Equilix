
# Equilix

Projeto desenvolvido para a disciplina de Jogos Digitais.

## Sobre o jogo

Equilix é um jogo 2D voltado para o treinamento de equilíbrio e coordenação motora.

O jogador deverá controlar um personagem utilizando os movimentos realizados em uma plataforma física equipada com sensores.

O objetivo é completar diferentes fases, superar obstáculos e melhorar o desempenho ao longo do jogo.

## Tecnologias

- Java
- libGDX
- IoT (Internet das Coisas)
- GitHub para versionamento

## Funcionalidades previstas

- Menu principal
- Personagem controlado por sensores
- Três fases com dificuldade progressiva
- Obstáculos durante o percurso
- Sistema de pontuação
- Registro do desempenho do jogador
- Opções de pausar e reiniciar

## Objetivo do projeto

Desenvolver um jogo simples e funcional que utilize a gamificação para auxiliar no treinamento de equilíbrio e coordenação motora.
